# Touch action artwork

The two PNG medallions were generated with the built-in `image_gen` tool on
2026-09-26 with `transparent_background=true`, then copied into this directory.
Their original alpha is preserved. Godot imports them at a maximum of 512px
to keep mobile texture memory modest; the source artwork remains unchanged.
The stick, Map, Gear, Talk, Pack, Force and Anchor graphics are native SVG assets authored
in this project. Gear and NPC meshes are generated by project code.
